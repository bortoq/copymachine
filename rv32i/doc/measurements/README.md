# Приёмка RV32I, 2026-10-19

83 сценария сравнивают фактические кадры commit, финальное состояние и всю
гостевую память с независимым rv32i_reference. Покрыты все 40 инструкций,
крайние значения и случайные регистры, x0, ветвления, переходы, память,
исключения, IO/EOF/ошибки и C-гость из examples/rv32i/smoke.c (28 инструкций).
Аудитор проверяет фактические операнды каждого такта vm1, включая патченные
адреса, src/src, fetch и канальные буферы. Проверен и обычный бинарник vm1.

cases.json сохраняет машинные байты, исходные регистры/данные, реальные
кадры, результат IO, SHA256 памяти и сырые окончания отчётов аудитора.
execution.log — журнал настоящего запуска. coverage.json — наблюдавшиеся
инструкции. monitor.json и monitor-cli.log подтверждают шесть сегментов
после commit: позиции ввода 2/2/4/4/4/4, восстановление без исходника,
совпадение всех кадров и итоговой гостевой памяти. Внешнее состояние
каналов передаёт вызывающая сторона; счётчики монитора modulo 2^32.

Команда замеров: make benchmark. Три последовательных процесса на одном
CPU, nice=15, максимум 768 МиБ адресного пространства на процесс,
ограничение CPU и общий таймаут. benchmark.json содержит исходные хеши,
версии toolchain, хеши бинарников и все выборки. Компилятор: riscv64-unknown-elf-gcc () 10.2.0.

- Подготовка C: 0.061 с; трансляция: 6.280 с.
- VM1: S=134217712 бит, P=8, A=27.
- Образ: 16777214 байт; boot: 3156204 байт.
- Код: 22826880 бит; данные генератора: 1575296 бит.
- Загрузка: 193 такта; исполнение: 54485 тактов.
- Медиана процесса: 68.614 мс; RSS: 4352 КиБ.

Процесс включает stdin boot и финальный снимок всей памяти. Отдельные
выборки загрузки сохранены в load_seconds; цена их вычитания из очень
короткой серии не является точной стоимостью одного гостевого такта.
Длинные Forth/GCC/Linux задания и аппаратные ресурсы не измерялись.

legacy-schedule.log подтверждает только структурную сборку старого
256-слотового ABI: 15496 слоёв при Layout 128 МиБ. Строгий запрет src/src
сделал прежний профиль 8 МиБ недостаточным. Прямой ABI использует
компактные слои P=8; расходы двух форматов нельзя смешивать.
