# language

Определение языка, написанное его собственными словами (`src/`), и всё для его проверки.

- Вход: текст определения; хостовый pForth32 (`boot/`) один раз компилирует из него L0, дальше L0 на эмуляторе компилирует определение само (L1 = L0).
- Выход: поток L0 (17 559 635 байт, совпадает с K0 модели `tests/reference`).
- Проверка: `make -C language check` (бут, замкнутость, тесты; нужен `cc -m32`); длинная — `make -C language check-self` (около 1,5–2 ч).
- Документация: [language.md](doc/language.md), [бут](doc/boot.md), [платформа](doc/platform.md).
- Ядро языка не доказано: механизм доказательства ([proof.md](doc/proof.md)) применён к тестовым словам.
