# language

Определение языка, написанное его собственными словами (`src/`), и всё для его проверки. Понятия (слово, ядро, бут, L0/L1, самосборка) объяснены в [README](../README.md#понятия), порядок изучения — в [руководстве](../docs/guide/README.md).

- Вход: текст определения; хостовый pForth32 (`boot/`) один раз компилирует из него L0, дальше L0 на эмуляторе компилирует определение само (L1 = L0).
- Выход: поток L0 (15 810 422 байта, совпадает с K0 модели `tests/reference`).
- Проверка: `make -C language check` (бут, замкнутость, тесты; нужен `cc -m32`); длинная — `make -C language check-self` (около 20 минут).
- Документация: [language.md](doc/language.md) (определение на русском), [ядро](doc/core.md), [бут](doc/boot.md), [платформа](doc/platform.md); перечень остальных — в [указателе](../docs/README.md).
- Ядро языка не доказано: механизм доказательства ([proof.md](doc/proof.md)) применён к тестовым словам.
