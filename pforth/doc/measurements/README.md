# Проверки этапа 8

`make -j1 check` прошёл десять запусков: пользовательский словарь,
арифметика и повторное исполнение определений; IF/ELSE, DO/LOOP,
BEGIN/UNTIL; переменная, переполнение 32 бит и область 60000 байт;
EOF без перевода строки, неизвестное слово, незавершённое определение,
длинная строка, реальные ошибки чтения/записи, пакет задания.
Запуск BYE проверен при открытом stdin. Новые SQUARE/SUM-TEN/AREA
проверены в конечной гостевой памяти и отсутствуют в исходном C-бинарнике.

Результаты — results.json; точные sparse PC/status журналы закодированы
в stderr_hex без потерь. Полные снимки, команды и входы сохранены в
build/verification, SHA256 снимков входят в результаты. Языковые тесты
используют исходный native runtime vm1 с наблюдателем; пакет задания —
обычный build/bitcopy/vm1. i386 не участвует в исполнении заданий.

Холодная инициализация до первого read выполнена внутри vm1 за 25,47 с;
результат — initialize.json, журнал — initialize.log. Она выполняется
один раз; тесты продолжают сохранённое пространство через artifact.resume.
Время отдельных случаев включает запуск, установку пространства и конечный
снимок, но исключает эту общую инициализацию. Это не измерение установившейся
скорости RV32I и не сравнение с C-vm2. Один CPU, nice=15, адресное пространство
768 МиБ на процесс; до 180 с сборке и до 360 с каждому языковому случаю.

check.log содержит успешные команды всего набора. runtime.log — проверки
изменённого чтения полей vm1 с побитным эталоном, обоих backend и CLI/SYS.
identities.json фиксирует исходники и native binaries. tested-image.json
сохраняет манифест холодного образа для полного набора.

После полного набора устранён __DATE__/__TIME__ upstream: по умолчанию
SOURCE_DATE_EPOCH=0. reproducibility.json подтверждает побайтное равенство
двух полностью собранных прямых артефактов. От исходного гостевого C-бинарника
изменились только 15 байт в строке даты/времени версии; машинный код тот же.
Свежий воспроизводимый вариант дополнительно исполняется в distcheck
вне исходного дерева с vendored зависимостями.

Исходные хеши upstream, исходного system.fth, заголовка и восстановленного
сырого PFD1 проверены tests/test_identity.py. Повторная подготовка i386
не выполнена: sandbox запрещает её системные вызовы, см. prepare-blocked.log.
