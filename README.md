# Архив legacy copymachine

Исходники и сопровождающие документы ранних реализаций и отложенных портов
(copy-space: C-эмулятор, ассемблер, copy-c, GCC/newlib, Linux; прежние
vm1/vm2, RV32I, pForth, copycode). Сгенерированное (сборки, копикод,
node_modules, кэши) не сохранено — при необходимости генерируется заново.
`legacy/git-bundles/*.bundle` — полные прежние истории
(`git clone legacy/git-bundles/copy-space.bundle`).
Работа до уборки 2026-10-30 — тег `archive-2026-10-30`.
