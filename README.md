# copymachine

Хостовый эмулятор и программы, выполняющие вычисления в адресном пространстве.
План работ — [ROADMAP.md](ROADMAP.md), карта — [docs/layout.md](docs/layout.md),
реестр переноса на Forth — [docs/components.md](docs/components.md).

- `emulator/` — хостовая машина, устройства и SYS.
- `space/` — copycode, vm2, RV32I и Forth. Действующие Python/C-реализации
  остаются при компонентах до приёмки замен на Forth.
- `tools/` — общие команды запуска, сборки и проверки.
- `docs/` — межкомпонентная документация; документация компонентов пока рядом с кодом.
- `build/` — физическое хранение образов, бинарников, выпусков и временных результатов.
- [`legacy/`](legacy/README.md) — единый архив прежних реализаций и отложенных приложений.

```sh
make -j1                 # собрать emulator и текущий Forth
./tools/run/forth        # запустить Forth интерактивно
make -j1 check          # последовательные проверки с ограничением ресурсов
```

Для начальной сборки нужны Python 3, make, хостовый C-компилятор и
RISC-V GCC для RV32I/ILP32. Компилятор задаётся RISCV_CC, находится в PATH
либо в локальном кэше build/space/rv32i/tmp/rv32i-toolchain.
make clean сохраняет этот кэш компилятора; готовые гостевые образы удаляются.

Проверить отсоединение архива и выпуски в чистом дереве:

```sh
make check-detached DETACHED_FLAGS=--releases
```

В Forth можно ввести `1 2 + .` и затем `bye`. Для запускателя доступны
`FORTH_SECONDS` (по умолчанию 600) и `FORTH_MEMORY_MIB` (768).
Сборщики передают явные пути в общий build/; ссылок каталогов у компонентов нет.
legacy/ необязателен для рабочего проекта и проверяется отдельной командой.

Проект эмулятора ранее назывался vm1. Исторические Python API `copycode.vm1`,
поля сохранённых образов и архивные журналы сохраняют свои идентификаторы.
Перенос каталогов не меняет формат уже собранных образов.

В этой среде корневой `.git` защищён от записи; метаданные находятся
в `.project-git`. Используйте `./project-git status`, `./project-git diff`
и остальные команды Git через эту обёртку. В обычном клоне работает стандартный Git.
Новый remote не добавлен. Прежние истории сохранены локально в `legacy/git/`.

Происхождение и лицензии MIT, Apache-2.0 и upstream-зависимостей сохраняются.
Карта сохранности исходников — `legacy/MIGRATION.json`;
проверка — `python3 -B tools/check_archive.py --require-local-history`.
