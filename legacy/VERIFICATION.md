# Проверки переноса

Перенесены 22 дерева/файла; SHA256 сверены для 475 исходных файлов.
Перепривязаны 52 прежние ссылки. Десять переделанных интеграционных файлов
оставлены в активном copy-space. Все три прежних Git HEAD сохранены;
истории находятся в `legacy/git/` и не входят в новый исходный снимок.

```sh
python3 -B tools/check_layout.py --require-local-history
```

Проверка также исключает gitlink, сборки, кэши и локальные настройки из индекса.
В обычном клоне без локальных архивов историй используется команда без
`--require-local-history`.

После переноса прошли:

- `make -C pforth -j1 distcheck`: самостоятельная сборка из исходного архива,
  встроенный словарь, задания, полный аудит 7 800 835 физических тактов,
  воспроизводимая переупаковка и clean;
- создание архивов emulator, vm2, copycode и проверка всех SHA256; ссылки в legacy
  материализуются обычными файлами, соседний каталог legacy не нужен;
- повторная сборка рабочего образа pForth; `1 2 + .` выводит `3`, `bye`
  завершает исполнение с кодом 0;
- свежий обычный Git-клон: все исходники из карты переноса доступны,
  работает Git и project-git, собирается нативный контроль vm2, создаются
  самостоятельные архивы copycode/pForth; дерево остаётся чистым.

Длительные проверки выполнены последовательно, на одном CPU, nice=15,
с ограничением памяти 768 МиБ и времени. Локальные результаты находятся
в `build/migration/`; карта путей и исходных хешей — `MIGRATION.json`.
Байты старых исходников, upstream и сырых исторических журналов сохранены.

После переименования проекта в emulator оригинальные пути и SHA256 остаются
в полях `old`/`sha256` карты. Поля `current`/`new` задают действующие пути;
`current_sha256` отдельно фиксирует исправления архивной документации
и старых путей запуска. Исходное состояние доступно в начальном Git-коммите.
Raw JSON/log-измерения и идентификаторы ABI сохранены без переименования.

Проверки переименования: оба backend runtime, 64 прямых и 70 гостевых
случаев vm2, самостоятельный выпуск pForth с полным аудитом тактов,
установка emulator/vm2 из архивов и запуск ранее сохранённого образа Forth.
Подробные журналы — `build/migration/emulator-*.log`, результаты установки
и совместимости — `emulator-install.json` и `emulator-existing-image.json`
в том же каталоге.
