# Спайк прямой компиляции Forth (9.5.1), 2026-10-20

`python3 -B tools/direct_spike.py` компилирует литерал, `+`, `DUP`, `DROP`,
`@`, `!` и цикл со счётчиком в индексный код на хостовой модели
`copycode.vm1.compute` и исполняет результат на checked-emulator (операнды
каждого такта проверяются). Число тактов не зависит от языка генератора,
поэтому спайк сделан на Python. Результат — `result.json`.

Варианты:

- **static** — глубина стека отслеживается при компиляции, ячейки стека —
  постоянные регистры: `DUP` — одно копирование, `DROP` — ничего;
- **memory** — стек в памяти, каждое обращение патчит адрес по указателю,
  указатель меняется чтением таблицы.

Слова памяти лежат с шагом 64 бит, поэтому патч адреса не даёт переноса.
Проверок диапазона и выравнивания нет: для `@`/`!` это нижняя граница.
Стоимость примитива — разность тактов программ с восемью повторами и без них.

| Такты | static | memory | pForth на RV32I |
|---|---:|---:|---:|
| литерал | 1 | 9,5 | |
| `DUP` | 1 | 12,8 | |
| `DROP` | 0 | 6,5 | |
| `+` | 27,5 | 43,5 | |
| `@` | 4,2 | 10,5 | |
| `!` | 4,2 | 23,5 | |
| итерация пустого `DO LOOP` | 57 | 57 | 5 324 |
| итерация `x @ + x @ 1 + x !` | 125 | 217 | 62 176 |

Для pForth на RV32I такты сняты наблюдателем на том же emulator: разность
100 и 10 итераций. Пример проверен: сумма 95 и `x = 15` в обоих вариантах.

## Выводы

- Оценка «30–100 тактов на примитив» подтверждена по порядку величины.
  Операции стека при отслеживании глубины почти бесплатны; итерация примера
  дешевле в 500 раз (static) и в 290 раз (memory), пустой цикл — в 93 раза.
- Время определяет последовательный тетрадный сумматор: 25 зависимых слоёв
  на `+` и на приращение счётчика цикла. Это цепочка зависимостей, её не
  сокращает планировщик: он только совмещает независимую работу.
- Поэтому общий планировщик 9.4.7 не на критическом пути. Важнее прямой
  компилятор 9.5 с отслеживанием глубины и откатом на стек в памяти, затем
  более быстрые сумматор и приращение (выбор переноса, префиксный инкремент)
  и стоимость проверок адресов. Планировщик — позже, как упаковка
  независимых строк, на подмножестве Forth, которое компилирует 9.5.
