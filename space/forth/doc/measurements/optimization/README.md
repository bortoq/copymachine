# Ускорения 8.5–8.7

Одинаковые входы выполнялись последовательно одним CPU, nice=15,
с лимитом 768 МиБ. Один полный холодный запуск каждого варианта на случай;
включены запуск, bootstrap, инициализация pForth и конечный снимок.
Все варианты исполняет исходный native runtime emulator с одинаковым sparse
наблюдателем для подсчёта физических тактов. Сборка исключена из времени.
Это не установившаяся скорость и не сравнение с C-vm2.

| Вход Forth | Линейный поиск, serial | Индекс, serial | Индекс, packing | Полный выигрыш |
|---|---:|---:|---:|---:|
| `0 dup drop drop` | 59,038 с | 3,836 с | 2,984 с | 19,79× |
| `1 2 + .` | 56,453 с | 3,627 с | 2,808 с | 20,10× |
| `: sq dup * ; 7 sq .` | 74,462 с | 4,984 с | 3,861 с | 19,29× |

Индекс дал 14,94–15,56× для этих полных запусков, группировка — ещё
1,29×. Встроенных слов 381, корзин 4096, максимальная исходная цепочка — 2.
Это фактические сквозные коэффициенты; сокращение числа кандидатов поиска
не приравнивается к ускорению всей программы.

benchmark.json содержит входы, вывод, состояния регистров, такты, SHA256
гостевой памяти/снимков/артефактов/исходников и полные sparse-журналы.
Гостевой RV32I-бинарник у index-serial и index-packed побайтно одинаков;
для каждого входа совпали все регистры и все 512 КиБ конечной гостевой памяти.
Сохранённые артефакты и снимки — build/performance. Текущая пересборка
build/pforth побайтно совпала с измеренным index-packed после окончательного
изменения адаптера. Явные контрольные варианты исключают подмену программы.

Расписание уменьшило число исходных слоёв с 8341 до 6815, native-код —
с 22570272 до 15290208 бит. Группируются статически доказанные независимые
копирования. Общие источники, зависимости и двухслойная задержка patch/fetch
проверены отдельными регрессиями, включая динамически адресуемую запись
в поле другой операции. Динамические диапазоны и каналы изолируются.

Проверки:

- 83 независимых случая RV32I: все 40 инструкций, память, IO, исключения,
  состояния и физические интервалы каждого такта emulator; rv32i.log.
- Commit/resume, source-free CLI и расписания; rv32i-sdk.log.
- 12 случаев Forth, включая исходный набор, переопределения, IMMEDIATE,
  SMUDGE, CONTEXT, записи C!/!/FILL/CMOVE и безопасный линейный fallback
  при произвольном изменении длины имени; checks.json и журналы.
- Реальный Forth на checked-emulator: 7800835 тактов, все фактические интервалы,
  источники, поля, fetch и устройства проверялись на каждом такте;
  native-audit.json. Число тактов совпало с измеренным упакованным вариантом.
- Реальная C-реализация индекса сравнена с линейным эталоном на всех
  встроенных именах, 1000 добавленных словах, коллизиях и мутациях; index.log.

Холодная инициализация нового образа до первого read заняла 1,706 с.
Это отдельный подготовительный запуск для тестов; benchmark всегда начинает
с холодного образа. Исторические измерения до оптимизаций сохранены выше.

Воспроизведение: make check, make check-native, make benchmark; команды
выполняются последовательно с ограничениями. Для benchmark лимит по умолчанию
420 с, для каждого дочернего гостя — 150 с. Полные copy-трассы не создаются.
