# Целочисленные утилиты Forth

`forth/integers.fth` — гостевая библиотека для 32-битных ячеек, MIT.
Двойные числа передаются как `(low high)`. Она использует имеющиеся
машинные примитивы pForth; ядро pForth пока остаётся C/RV32I.

| Слово | Стек | Семантика |
|---|---|---|
| `WITHIN`, `cc-within` | `( u low high -- flag )` | Беззнаковый полуинтервал, включая переход через 2^32 |
| `cc-du<` | `( lo1 hi1 lo2 hi2 -- flag )` | Беззнаковое сравнение 64 бит |
| `cc-du=` | `( lo1 hi1 lo2 hi2 -- flag )` | Равенство 64 бит |
| `cc-du+?` | `( lo1 hi1 lo2 hi2 -- low high overflow )` | Сумма по модулю 2^64 и признак переноса |
| `cc-d-` | `( lo1 hi1 lo2 hi2 -- low high )` | Разность по модулю 2^64 |
| `U.` | `( u -- )` | Беззнаковый вывод в текущей системе счисления с пробелом |

Для `U.` допустим `BASE` от 2 до 36; иначе `THROW -24` до вывода цифр.
Логическая истина — -1, ложь — 0. Библиотека не выделяет память и
не использует глобальное рабочее состояние; при загрузке устанавливает DECIMAL.

Проверка `make -C space/forth -j1 check-integers` выполняет код в пространстве:
перенос между ячейками, переполнение 64 бит, заём при вычитании,
знаковый старший бит в беззнаковых сравнениях, переход интервала через ноль,
вывод 4294967295 в десятичном/шестнадцатеричном виде и ошибку BASE.
Доказательства запуска: `build/space/forth/build/verification/integers/`.
