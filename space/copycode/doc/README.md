# Владение и форматы

`src/copycode/vm2/` — перенесённый MIT-код из vm2: потоковый boot,
SYS, кооперативный PCS1 и динамический PCS2 monitor, SPT1/SPT2, checkpoint,
transport и независимая проверка расписаний. Это **формат троек vm2**,
не вход для emulator. Импорты: `copycode.vm2.*`; переходники: `compat/vm2/`.
Старые пути vm2 содержат только переходники.
Исключение по происхождению и лицензии — `vm2/arithmetic.py`: общий
32-битный carry-сумматор из copy-space (Apache-2.0). Он принимает интерфейс
символического генератора и scratch-сигналы, не зависит от адресов и ISA RV32I.
`legacy-proto.def` — замороженный снимок старого контракта vm2, не новый
источник изменений SYS. Схема новой машины принадлежит emulator/src/proto.def.

`src/copycode/vm1/` — генераторы четырёхиндексного ABI rev1. `machine.Format`
задаёт битовые поля, слои, каналы и проверяет все полуинтервалы, включая src/src.
`boot.iter_boot` — потоковый установщик; `program.Program` — конечная цепочка
слоёв. Внутренняя функция copy(n,dst,src) — удобство генерации четырёх полей,
не формат инструкций пространства. Boot/Program требуют кратных байту S и
размера процессора, boot требует P>=8. Сам эмулятор имеет более широкий контракт.

`lib.reverse_byte` переводит физический порядок битов байта в числовой и обратно;
области по 8 бит различны. `lib.add8` — восьмибитное сложение в пространстве:
таблица полного одноразрядного сумматора, патч двух границ будущего копирования
в разных тактах, 40 прикладных слоёв. Результат mod256. Адреса аргументов,
результата, временной пары и LUT передаются явно; их область не пересекает код.
Никакой результат конкретных аргументов генератором не вычисляется.

`sys.record/fstat` читает явную зависимость proto.def; запрос и ответ — разные
такты, использование ответа ещё позже. `monitor.emit/status` выводит живые
данные и VMS1 через обычные каналы. `checkpoint.snapshot` выводит сырую память
через fd4, подставляя явный слой продолжения вместо текущего процессора.
Курсоры внешних файлов сохраняет запускающий инструмент. Сам эмулятор не
сохраняет и не восстанавливает снимки. Для vm2 сохранены прежние SPT1/SPT2 и PCS2;
новые минимальные модули emulator не объявляются двоично совместимыми с ними.

`../../legacy/copycode/legacy/copy-space/` — архив Apache-2.0 прежнего ABI. Старый add8 использует
жёсткие адреса, статусные позиции и загрузчик; он не поддерживается emulator/vm2.
Демонстрации demo/halt/proof не являются самостоятельными продуктами.
Архив не подключается к активной библиотеке через вложенный legacy/.

RV32I выделен в соседний rv32i/. Старые GCC/copy-c остаются в общем legacy/. Интеграционные `space_segments.py` и
`space_trace_audit.py` содержат старые host dump/trace и остаются переходниками:
их новый путь уже делегирует checkpoint/PCS2; копировать их целиком неверно.

Monitor/checkpoint остаются в одном проекте: общие форматы и transport,
единый цикл проверки и выпуска. Оснований для новых проектов сейчас нет.
Реестр исходников/символов/лицензий — inventory.json; ABI и входы/выходы каждого
модуля — contracts.json; размеры и идентичности нового кода — generated.json.
