# Программы пространства

- [copycode](copycode/README.md) — общие генераторы, форматы, библиотеки,
  отдельные планировщик и оптимизатор.
- [vm2](vm2/README.md) — трансляция адресов и исполнение копикода.
- [rv32i](rv32i/README.md) — RV32I и адаптация программ.
- [forth](forth/README.md) — текущий pForth и его среда.

Целевая реализация — скрипты Forth внутри пространства. Пока они не готовы,
Python/C-код остаётся при использующем его компоненте. Это сохранение рабочего
пути, а не завершённая миграция. Общие библиотеки будут выделяться по назначению
при переносе, без создания пустых каталогов заранее.

[Полный перечень компонентов и пункты миграции](../docs/components.md).
