# Платформа, время, определение на хосте (15.3)

Тип адресации определения — номер платформы: позиция таблицы «платформа», которой соответствует
пространство, где определение исполняется и проверяется, и способ запуска там. Мера цены на любой
платформе — время. Тест — `tests/test_platform.py`.

## Слова

Слова есть только в программе, которая называет одно из них (потребность 128 у `fc-scan-uses`,
вместе с 1, 2, 16, 32, 64: умножение, деление, доказательство, замена, длинное копирование); их
определения написаны на языке (`fc-platform`, `fc-time-price`), кроме генератора host (`gen-host`).

| Слово | Что делает |
|---|---|
| platform ( p -- xt ) | таблица платформ: xt слова ( x d -- r ), исполняющего определение d на платформе p; 0 — гест (d — xt, `execute`), 1 — хост (d — номер K программы хоста) |
| platform-of ( xt -- p ) | платформа текущего определения понятия xt: 1, если у него есть определение на хосте, иначе 0 |
| time ( xt -- ns err ) | исполняет `0 xt` (результат снимается) один раз, затем 7 раз по часам (удалённое пространство 1): ns — наименьшее время, err — второе по величине минус наименьшее |
| host NAME | внутри определения `:` делает его определением NAME на хосте (платформа 1) |
| replace ( xt concept -- ok ) | в такой программе цена — время (ниже) |

Номер платформы — в записи определения: поле хост пространства (ячейка 8 записи компилятора,
ячейка 12 записи программы, `doc/word.md`, `doc/replace.md`) — K + 1 у определения host, иначе 0.
Замена копирует его вместе с определением, поэтому после замены понятие исполняется там, где
исполняется кандидат.

## Определение на хосте

`: f-host host f ;` — определение f на хосте. Компилятор переводит текст f (первое `: f` в тексте
программы) в программу C: слова определения — генераторы `+ - * and or xor lshift rshift dup drop
swap over` (на ячейках, по модулю 2^32; сдвиг больше 31 даёт 0), числа и цифры; слово программы
переводится на месте (вложение до 16); комментарий `(` пропускается; другое — `throw` -13. Слово f
должно быть ( x -- r ).

Программа хоста K (не больше 16): текст C в потоке с позиции HB + 32, его длина в битах — в ячейке
HB = 2^30 + 2^29 + 2^22·K. Исполнение — слово %host ( x k -- r ):

1. в первый раз: команда `: > host.c` (файл текста пуст), текст пишется длинным копированием в
   удалённое пространство 2 (`host.c`), команда `cc -O2 -o hK host.c` (K — буква a, b, …);
2. x пишется в удалённое пространство 3 (`host.io`) с позиции 0, команда `./hK`: программа читает x,
   исполняет определение и пишет r с позиции 32; r читается длинным копированием.

Команда — запрос EXEC через удалённое пространство 0 (прежний SYS). Эмулятор запускается в каталоге
программ хоста с `-r host.c -r host.io`; нужен компилятор C хоста `cc`.

## Время и замена

В программе платформ `replace` сравнивает время кандидата и понятия: оба исполняются по очереди
(по 7 раз после одного прогона каждого), время — наименьшее, погрешность — второе по величине минус
наименьшее. Время равно (2.11.5), если разница меньше суммы погрешностей. Кандидат проходит, если
его время меньше и не равно; при равном — если у него меньше копирований, при равных — бит, при
равных — слоёв (цены обоих должны быть известны при компиляции, иначе отказ 3). Остальное — как в
14.13: сначала артефакты (таблица последней проверки понятия, рабочим словом проверки), точность.

Так `replace` выбирает более быстрое определение на хосте или в гесте: дорогое слово уходит на
хост, дешёвое остаётся в гесте или возвращается в гест; два определения на хосте одного слова равны
по времени, и заменяет то, у которого меньше копирований.
