# Программы пользователя не дорожают (14.14)

При перекомпиляции языка программа пользователя перекомпилируется; новый код принимается, если его
цена не выше (и артефакты те же), иначе остаётся прежний. Механизм — инструмент вне ядра:
`tools/user_programs.py`; тест — `tests/test_user_programs.py` (`make -C space/language
check-user-programs`, около 45 с). Ядро, L0 и `doc/language.md` не менялись: L0 по-прежнему
**16 967 309** байт и равен K0 модели, потоки 37 программ равны модели.

## Почему вне ядра

Определению языка этот механизм не нужен: язык не вызывает себя на программах пользователя, а
программа пользователя — не часть определения. Слово ядра добавило бы записи в `doc/language.md` и
байты в L0 (который уже больше 16 МиБ), не давая определению языка ни одной новой возможности. Всё, что
механизм использует, уже есть: цена слова (14.11, запись компилятора), слово `price`, потоки бута.
Инструмент только сравнивает эти числа и выбирает, какой поток оставить. Если автор решит, что
перекомпиляцию должен выполнять сам язык в гесте, понадобятся хранилище программ в пространстве и
слово сравнения цен: это отдельный пункт.

## Устройство

- **Язык** (`Language`) — тексты `src/` (или другого каталога с теми же файлами). `replaced(слово,
  определение)` ставит на место определения слова другое (замена вручную, без проверки цены языка).
  `boot()` перекомпилирует язык: хостовой pForth исполняет определение и выдаёт L0 (как `tools/boot.py`).
- **Хранилище** (`Store`) — каталог, в нём для каждой программы: `source.fth`, `code.stream` (текущий код
  — поток бута), `output.bin` (эталонный артефакт — вывод на checked-emulator), `record.json` (хеш
  языка, цены слов, сумма, история перекомпиляций), `stack/NNN.stream` (стек прежних кодов).
- **Цена программы.** Компилятор даёт каждому слову размер, биты, копирования и слои (14.11); `price`
  инструмента — та же сумма, что у генератора `gen-price` (тест сверяет их программой `1 2 3 4 price`).
  Цена программы — цена каждого слова, определённого в ней через `:`, и их сумма. Слова с ценой «по
  исполнению» учитываются только размером. С `--measure` сравнивается ещё цена исполнения всей
  программы по счётчикам 13.4 (`tools/counters.py`): размер слов + биты + копирования + слои тактов.
- **Правило.** `words` (по умолчанию): код принят, если ни одно слово с ценой, известной при
  компиляции, не подорожало и сумма не выше; `total`: достаточно, чтобы сумма не выросла. Равная цена —
  принято. Сверх цены нужно, чтобы вывод программы был тем же (причина отказа `artifacts`); язык,
  который не компилирует программу, отвергнут (`error`).
- **Исходы** `Store.recompile`: `same` — тот же код (в историю записана запись); `accepted` — другой код,
  прежний ушёл в стек; `refused` — остался прежний (причина `price`, `artifacts`, `error`, в истории —
  подробность, например `dearer words: inc 54220 -> 55280`).

Командная строка: `user_programs.py add STORE NAME FILE [--language DIR]`, `recompile STORE [--language
DIR] [--rule words|total] [--measure] [--boot L0]`, `show STORE`.

## Тест

Три программы: `cells` (циклы, `cells`, `1+`), `plain` (только `*`), `mix` (три `cells` в слове и одно
`1+` в другом). Языки: `src/`; «дорогой cells» (`gen-cells` двумя сдвигами вместо одного); «дорогой 1+»
(`gen-1+` через литерал и `gen+`); «плохой 1+» (прибавляет -1: та же цена); «ломаный» (`gen-cells`
бросает -13); комментарий в `gen-decimal` (язык изменён, цена нет).

| Шаг | Итог |
|---|---|
| программы скомпилированы дорогим cells, язык заменён на `src/` | cells 110 894 → 109 835, mix 377 316 → 367 773 (приняты); plain тот же код; принятый код равен прямой компиляции языком `src/` и потоку модели; прежний код в стеке, исполняется; цена исполнения cells 2 327 412 → 2 316 391 |
| программы скомпилированы `src/`, язык заменён на дорогой cells вручную | cells и mix — прежний код побайтно (отказ: цена), цена не выросла; дорогой код был бы дороже; plain тот же; комментарий в языке — тот же код |
| от дорогого cells к дорогому 1+ | mix: c3 33 607 → 30 424, inc 54 220 → 55 280, программа 377 316 → 370 951: правило `words` отказывает, `total` принимает |
| плохой 1+ / ломаный cells | отказ `artifacts` / отказ `error`, код остаётся |
| бут | язык `src/` даёт L0 сборки (16 967 309 байт), язык с дорогим cells — другой (17 000 469) |

## Решения исполнителя (автор может изменить)

1. **Механизм — инструмент, а не слово ядра** (см. выше). Язык вне ядра не хранит программы.
2. **Единица принятия — вся программа, а не слово.** Вызовы связаны при компиляции, потому код слова
   нельзя взять из старого потока, а остальные — из нового (адреса слоёв другие). Поэтому «слова не
   дорожают» обеспечено правилом `words` для всей программы: либо весь новый код, либо весь прежний.
   Связывание через ячейки понятия (14.13) позволило бы принимать слова по одному; это не делалось
   (в программе замены у каждого слова ячейка понятия есть, в остальных программах нет).
3. **Правило по умолчанию — `words`** (ни одно слово не подорожало), а не сумма: так читается 2.10.4
   («слова, определения которых не дорожают»). Сумму (2.2.7, предложение) даёт `--rule total`.
4. **Слова с ценой по исполнению не сравниваются по отдельности.** У них есть только размер, и он
   меняется от выравнивания ячеек, даже когда слово, которое они вызывают, стало меньше (в тесте
   `fill` 175 → 177 при более дешёвом `slot`). Они входят в сумму; точнее их цену даёт `--measure`.
5. **Артефакты — условие принятия**, хотя пункт говорит только о цене: более дешёвый код с другим
   выводом принимать нельзя (как в 14.13). Артефакт программы — её вывод на пустом входе.
6. **Цена программы не включает подпрограммы `*` и `/`** (их размер не в слове пользователя); их цена
   вызова входит в цену вызывающих слов.
7. **Язык перекомпилируется хостовым pForth** (то же определение, первый исполнитель бута); программа
   компилируется хостом, а не L0 на emulator: хост — секунды, ядро L0 — минуты на программу. Ядро L0
   даёт тем же словам цену на метку входа изоляции больше (14.10, `doc/word.md`), поэтому цены хоста
   и ядра не смешиваются: хранилище держит цены одного исполнителя.
8. **Язык после изменения проверяется только как определение, которое бутится** (`Language.boot`);
   замыкание (`check-closure`) для изменённых копий не запускалось.

## Что не закрыто

- Перекомпиляцию выполняет инструмент на хосте, а не язык в гесте; хранилище — файлы хоста.
- Принятие по слову (с ячейками понятия) не сделано; зависимые слова не пересчитываются отдельно.
- Цена программ с циклами при компиляции известна только размером; точнее — `--measure` (счётчики на
  Python, медленно для больших программ; предел 2 000 000 тактов).
- Формула `price` в инструменте записана отдельно от `gen-price` (сверяется тестом); если автор
  заменит `price` в языке, инструмент не последует за ним.
- Программы со входом (`key`) не поддержаны: артефакт — вывод на пустом входе.
