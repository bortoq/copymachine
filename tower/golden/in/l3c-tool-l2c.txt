# The compiler of language 2 (23.8), a program of the chain (languages 1-3), as hex2 of stage0 is a program of its own
# language. stdin: the text of language 2 (tower/l2text.py) and a zero byte; stdout: the text of language 1 (what the seed
# programs/seed.tw reads) and a zero byte. Language 2 is language 1 with two words and names of parts of space:
#   c n d s    copy: the row  r d d+n s s+n  (the sums are made here, by add)
#   d n v      data: n bits of v, the lowest first, as a line `s 0101...`
#   :x         a label: x is the position of the text, counted in bits of the image from the start (or from `o`)
#   o          the origin: the position is 0 from here
#   w r z s #  as in language 1: they go out as they stand, the compiler counts their bits (w: A, a row is 4A bits,
#              z: N bits, s: the 0 and 1 characters, d: n bits); the rest of an r, s, # line is not looked at
# A number is hex (at most 5 digits), or &x (a label defined before), or &x+k. A wrong text is reported to stderr and the
# compiler halts (7.2.28): bad text (a letter that is no command, a wrong character), bad count (a wrong number of
# numbers in a line), bad label (repeated, or not defined yet). What is not checked: numbers over 5 digits, w z d over ff.
# The tables: cls turns a byte into its class (flags, the value of a digit, the code of the command letter), attr gives the
# attributes of a command: the number of numbers, echo (the line goes out as it stands), numeric, skipping, bits, valid, row,
# label. Their numbers are made by tower/l2text.py (cls_table, attr); a test compares them with this text.
# One state of the line is flags in a row (fl): numeric, skipping, echo, (the zero byte), bits, (a bit character); the token
# (V, W, amp, lbl, dig) is one register tv, so a line or a token ends with one copy. A table has one index: two flags that
# make it are copied side by side.

# --- cls: the byte (the first bit of the stream is the lowest) -> bit 0 a character 0 or 1, 1 hex digit, 2 separator,
#   3 line break or zero byte, 4-7 the value of a digit (or 5 &, 6 +), 8-11 the code of the command letter (: is 9)
#   (w 1, r 2, z 3, s 4, # 5, c 6, d 7, o 8), 12 a lowercase letter, 13 the zero byte

# --- attr: the code of a command -> bits 0-3 the number of numbers, 4 numeric, 5 skipping, 6 echo, 8 bits, 9 valid, 10 row, 11 label
