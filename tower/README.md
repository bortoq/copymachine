# tower — цепочка вложенных языков 1–5 (этап 23)

Каждый язык — несколько слов и компилятор в нижний: 1 — строка `dl dh sl sh`; 2 — `copy n d s`, данные;
3 — таблицы, блоки, вызовы, библиотека (`add`, `eq`, …); 4 — длинное копирование; 5 — цена. Над ними текст
программ (`text.py`, `programs/*.tw`: метки и слова языков 2–4). Подробно — `docs/measurements/tower.md`.

## Зерно (с 23.7, шаг A) и что временно

Как hex0 у stage0: зерно — то, что нужно, чтобы собрать всё остальное, и оно собирает само себя.

- **Зерно** = эмулятор + `programs/seed.l1`: текст языка 1 (`l1text.py`: строки `w`, `r dl dh sl sh`, `z`, `s` биты,
  `#`) образа кодера языка 1. Кодер — программа цепочки (`programs/seed.tw`, языки 1–3, 213 строк): читает
  текст языка 1 со stdin (до нулевого байта), пишет на stdout образ эмулятора. Таблица сложения `add4` в
  `seed.l1` — голые биты (`s ...`), её никто не вычисляет.
- **Неподвижная точка:** образ кодера, запущенный на `seed.l1`, даёт самого себя побайтно (тест `test_seed.py`).
- **Временно** (заменяются в 23.8–23.9 программами цепочки): Python `l2.py`–`l5.py`, `lib.py`, `text.py` (разбор
  текста `.tw`, метки, проверки), `progs.py`, `l1.py`, `l1text.py` (генератор `seed.l1` и Python-эталон кодера).
- Ошибка текста языка 1 — сообщение в stderr (слово `warn`, канал S+3) и останов: образ обрывается на этом месте
  (7.2.28, без исключений). Не проверяются (определено, но дорого): число длиннее 4 цифр, значение шире `w` бит,
  `w`/`z` больше `ff`.

## Как собрать и проверить

    make -C emulator all checked                           # эмулятор (тесты делают это сами)
    python3 -B tower/l1text.py tower/programs/seed.tw > tower/programs/seed.l1    # заново сгенерировать зерно
    python3 -B -m tower.text < tower/programs/echo.tw > echo.img                  # текст .tw -> образ (Python)
    python3 -B tower/l1text.py -e < tower/programs/seed.l1 > seed.img             # текст языка 1 -> образ (Python)
    # то же в пространстве: образ, текст и нулевой байт на stdin эмулятора (A=16, P=7 печатает text.py)
    { cat seed.img; cat tower/programs/seed.l1; printf '\0'; } | emulator/build/bitcopy/emulator -s 65530 -p 7 | cmp - seed.img
    make check-tower                                       # все тесты цепочки (checked, ~14 с)

Эмулятор получает `образ + текст + 0` на stdin, как в `common.run`. После правки `seed.tw`
пересоздать `seed.l1` (тест `test_seed_text_is_current` скажет, если забыли).
