# tower — цепочка вложенных языков 1–5 (этап 23)

Каждый язык — несколько слов и компилятор в нижний: 1 — строка `dl dh sl sh`; 2 — `copy n d s`, данные;
3 — таблицы, блоки, вызовы, библиотека (`add`, `eq`, …); 4 — длинное копирование; 5 — цена. Над ними текст
программ (`text.py`, `programs/*.tw`: метки и слова языков 2–4). Подробно — `docs/measurements/tower.md`.

## Зерно (с 23.7, шаг A; с 23.8 — шаг B; с 23.9 — метки) и что временно

Как hex0 у stage0: зерно — то, что нужно, чтобы собрать всё остальное, и оно собирает само себя.

- **Зерно** = эмулятор + `programs/seed.l1`: текст языка 1 (`l1text.py`: строки `w`, `r dl dh sl sh`, `z`, `s` биты,
  `#`) образа кодера языка 1. Кодер — программа цепочки (`programs/seed.tw`, языки 1–3, 213 строк): читает
  текст языка 1 со stdin (до нулевого байта), пишет на stdout образ эмулятора. Таблица сложения `add4` в
  `seed.l1` — голые биты (`s ...`), её никто не вычисляет.
- **Неподвижная точка:** образ кодера, запущенный на `seed.l1`, даёт самого себя побайтно (тест `test_seed.py`).
- **Шаг B (23.8): компилятор языка 2** — программа цепочки `programs/l2c.tw` (языки 1–3, A=18, 290 слоёв, образ 20 228
  байт): читает текст языка 2 (`l2text.py`) и пишет текст языка 1 с нулевым байтом — то, что читает кодер. Слова языка 2:
  `c n d s` (копия: строка `r d d+n s s+n`), `d n v` (данные), `:x` (метка = позиция в битах текста, одна строчная
  буква, ссылка назад), `o` (начало отсчёта); строки языка 1 (`w r z s #`) идут как есть, компилятор считает их биты.
  Раскладка = порядок текста (метка — как в hex2); распределитель с выравниванием не сделан, ссылки вперёд и длинные имена — в `l2l`.
  Строки каналов (stdin/stdout/stderr) и загрузочная — язык 1 (`r`): у них длина приёмника и источника разные. Цепочка
  собирает себя без Python: `seed.l1` → кодер → `l2c.l1` → `l2c`; `l2c` на `l2c.l2` (его текст языка 2) даёт `l2c.l1`.
  Числа теперь до 5 hex-цифр (20 бит; нужно для A=18): в кодере `V` — 20 бит.
- **Метки (23.9, часть 1): `programs/l2l.tw`** — следующий инструмент цепочки (как M0 после hex2; языки 1–3, A=19, 529 слоёв,
  образ 40 510 байт). Текст языка 2 с метками `:имя` (a-z 0-9 `_`, 1–15 байт) и ссылками `&имя`, `&имя+k` **вперёд и назад**
  (таблица на 255 имён, поиск `eq` по двум половинам имени и тегу). Два прохода: stdin читается один раз, поэтому **текст
  подаётся дважды** (`text 0 text 0`, как `cat t t`; хост дублирует вход, программа текст не хранит): первая копия определяет
  метки, вторая пишет текст языка 1 и нулевой байт; метка во второй копии обязана стоять там же, где в первой. Ошибки:
  `l2l: bad text` / `bad count` / `bad label` (повтор, неопределённая, 256-я, копии разные). Сборка без Python: `seed.img` на
  `l2l.l1` даёт образ; `l2c` на `l2l.l2` даёт `l2l.l1`; `l2l` на `l2l.l2` (дважды) даёт `l2l.l1` (неподвижная точка). Эталон —
  `l2ltext.py`, пример — `hello_names.l2` (вывод равен выводу `l2c` на `hello.l2`). Дальше — компилятор языка 3 (части 2–3).
- **Временно** (заменяются в 23.9 программами цепочки): Python `l2.py`–`l5.py`, `lib.py`, `text.py` (разбор
  текста `.tw`, метки, проверки), `progs.py`, `l1.py`, `l1text.py` (генератор `seed.l1`, `l2c.l1`, Python-эталон
  кодера), `l2text.py` (Python-эталон `l2c` и перевод текста языка 1 в язык 2), `l2ltext.py` (Python-эталон `l2l`).
- Ошибка текста языка 1 — сообщение в stderr (слово `warn`, канал S+3) и останов: образ обрывается на этом месте
  (7.2.28, без исключений). Не проверяются (определено, но дорого): число длиннее 5 цифр, значение шире `w` бит,
  `w`/`z` больше `ff`.

## Как собрать и проверить

    make -C emulator all checked                           # эмулятор (тесты делают это сами)
    python3 -B tower/l1text.py tower/programs/seed.tw > tower/programs/seed.l1    # заново сгенерировать зерно
    python3 -B -m tower.text < tower/programs/echo.tw > echo.img                  # текст .tw -> образ (Python)
    python3 -B tower/l1text.py -e < tower/programs/seed.l1 > seed.img             # текст языка 1 -> образ (Python)
    # то же в пространстве: образ, текст и нулевой байт на stdin эмулятора (A=16, P=7 печатает text.py)
    { cat seed.img; cat tower/programs/seed.l1; printf '\0'; } | emulator/build/bitcopy/emulator -s 65530 -p 7 | cmp - seed.img
    python3 -B tower/l1text.py tower/programs/l2c.tw > tower/programs/l2c.l1     # зерно шага B (как seed.l1)
    python3 -B tower/l2text.py tower/programs/l2c.l1 > tower/programs/l2c.l2     # то же, копии как `c n d s`
    python3 -B tower/l2text.py -e < prog.l2 > prog.l1z                            # эталон l2c: язык 2 -> язык 1 + 0
    # цепочка: seed.img(l2c.l1) = l2c.img; l2c.img(prog.l2) = текст языка 1; seed.img(он) = образ (A=18, P=19 у l2c)
    python3 -B tower/l1text.py tower/programs/l2l.tw > tower/programs/l2l.l1     # инструмент меток (так же: .l2 из .l1)
    python3 -B tower/l2ltext.py -e < prog.l2 > prog.l1z                           # эталон l2l (сам удваивает текст)
    # l2l.img = seed.img(l2l.l1); текст дважды на stdin эмулятора (A=19, P=20 печатает text.py):
    { cat l2l.img; cat prog.l2; printf '\0'; cat prog.l2; printf '\0'; } | emulator/build/bitcopy/emulator -s 524282 -p 20 > prog.l1z
    make check-tower                                       # все тесты цепочки (checked, ~63 с)

Эмулятор получает `образ + текст + 0` на stdin, как в `common.run`. После правки `seed.tw`
пересоздать `seed.l1` (тест `test_seed_text_is_current` скажет, если забыли).
