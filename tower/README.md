# tower — цепочка вложенных языков 1–5 (этап 23)

Каждый язык — несколько слов и компилятор в нижний: 1 — строка `dl dh sl sh`; 2 — `copy n d s`, данные;
3 — таблицы, блоки, вызовы, библиотека (`add`, `eq`, …); 4 — длинное копирование; 5 — цена. Над ними текст
программ (`text.py`, `programs/*.tw`: метки и слова языков 2–4). Подробно — `docs/measurements/tower.md`.

## Зерно (с 23.7, шаг A; с 23.8 — шаг B; с 23.9 — метки и язык 3) и что временно

Как hex0 у stage0: зерно — то, что нужно, чтобы собрать всё остальное, и оно собирает само себя.

- **Зерно** = эмулятор + `programs/seed.l1`: текст языка 1 (`l1text.py`: строки `w`, `r dl dh sl sh`, `z`, `s` биты,
  `#`) образа кодера языка 1. Кодер — программа цепочки (`programs/seed.tw`, языки 1–3, 213 строк): читает
  текст языка 1 со stdin (до нулевого байта), пишет на stdout образ эмулятора. Таблица сложения `add4` в
  `seed.l1` — голые биты (`s ...`), её никто не вычисляет.
- **Неподвижная точка:** образ кодера, запущенный на `seed.l1`, даёт самого себя побайтно (тест `test_seed.py`).
- **Шаг B (23.8): компилятор языка 2** — программа цепочки `programs/l2c.tw` (языки 1–3, A=18, 290 слоёв, образ 20 228
  байт): читает текст языка 2 (`l2text.py`) и пишет текст языка 1 с нулевым байтом — то, что читает кодер. Слова языка 2:
  `c n d s` (копия: строка `r d d+n s s+n`), `d n v` (данные), `:x` (метка = позиция в битах текста, одна строчная
  буква, ссылка назад), `o` (начало отсчёта); строки языка 1 (`w r z s #`) идут как есть, компилятор считает их биты.
  Раскладка = порядок текста (метка — как в hex2); распределитель с выравниванием не сделан, ссылки вперёд и длинные имена — в `l2l`.
  Строки каналов (stdin/stdout/stderr) и загрузочная — язык 1 (`r`): у них длина приёмника и источника разные. Цепочка
  собирает себя без Python: `seed.l1` → кодер → `l2c.l1` → `l2c`; `l2c` на `l2c.l2` (его текст языка 2) даёт `l2c.l1`.
  Числа теперь до 5 hex-цифр (20 бит; нужно для A=18): в кодере `V` — 20 бит.
- **Метки (23.9, часть 1): `programs/l2l.tw`** — следующий инструмент цепочки (как M0 после hex2; языки 1–3, A=19, 541 слой,
  образ 59 937 байт). Текст языка 2 с метками `:имя` (a-z 0-9 `_`, 1–15 байт) и ссылками `&имя`, `&имя+k` **вперёд и назад**
  (таблица на 1024 имени; поиск — хеш: два последних байта имени `c1 + 4·c2` берут цепочку записей, дальше тег и `eq` половин). Два прохода: stdin читается один раз, поэтому **текст
  подаётся дважды** (`text 0 text 0`, как `cat t t`; хост дублирует вход, программа текст не хранит): первая копия определяет
  метки, вторая пишет текст языка 1 и нулевой байт; метка во второй копии обязана стоять там же, где в первой. Ошибки:
  `l2l: bad text` / `bad count` / `bad label` (повтор, неопределённая, 1025-я, копии разные). Сборка без Python: `seed.img` на
  `l2l.l1` даёт образ; `l2c` на `l2l.l2` даёт `l2l.l1`; `l2l` на `l2l.l2` (дважды) даёт `l2l.l1` (неподвижная точка). Эталон —
  `l2ltext.py`, пример — `hello_names.l2` (вывод равен выводу `l2c` на `hello.l2`).
- **Компилятор языка 3 (23.9, часть 2; часть 3 — он собирает себя): `programs/l3c.tw`** — программа цепочки (языки 1–3), текст языка 3 → текст
  языка 2 с метками (вход `l2l`; вывод кончается нулевым байтом, поэтому `cat out out` — это `text 0 text 0`). Цепочка сборки: **текст языка 3 →
  `l3c` → `l2l` → `seed` → образ**. Раскладка **серийная** (строка = слой из двух слотов: строка и прыжок; P=2, A=20 фиксирован); упакованная —
  со словом `pack` первым и проходом `l3p` (следующий пункт). Вход — подмножество текста `text.py`: слова `data table array copy shl shr lut store block word goto if call ret halt emit
  warn key add sub band lt eq`, числа десятичные, строки до 32 байт, ссылки `&имя[lo:hi]`, входной блок `main`, данные и таблицы вне блоков, таблицы и массивы
  до 2^10 записей; нет языка 4, `stack/rec`, `dec<n>`, `0x`. Таблицы `add4 sub4 hex4` (и `and4 lt4c eq4c` для слов библиотеки) порождаются в конце образа
  по использованию. Таблица имён данных — 1024 места (1020 имён пользователя; в `l3c.tw` 370, поиск линейный); блоков и слов в тексте `l3c.tw` 504, меток
  `l2l` 542 из 1024. Ошибки: `l3c: bad text / bad label / bad width / bad block / too big`, вывод обрезан. Подмножество, раскладка и ошибки подробно — в
  `l3ctext.py` (Python-эталон; `hoist` переносит данные программ `text.py` из блоков). **Неподвижная точка (часть 3):** текст языка 1 инструмента
  `programs/l3c.l1` (242 577 байт) `seed` превращает в образ `l3c` (A=20, P=2, 126 004 байта); этот образ на `l3c.tw` → `l2l` → `seed` даёт тот же `l3c.l1` и
  тот же образ побайтно (Python на этом пути нет). `l3c.l1` создан один раз цепочкой, начатой с образа Python (`compile_program(..., serial=True,
  hi=22)`, упакованный P=3, 105 764 байта: другая раскладка, тот же вывод). Тесты: `tests/test_l3c.py` (в `check-tower`: эталон, ёмкости в текстах, малые
  программы), `tests/long_l3c.py` (`make check-tower-long`: инструменты, собранные `l3c`, 300 порч, 1020/1021 имя, неподвижная точка).
- **Планировщик (23.10): `programs/l3p.tw` и слово `pack`** — улучшение экономного языка: раскладка строк по слоям отдельным проходом над серийным выходом `l3c`
  (в `l3.py` он был всегда, `plan=True`; на цепочке его не было). Текст языка 3, **первое слово которого `pack`**, — режим упаковки: процессор из трёх слотов (P=3:
  загрузочный и первый слой блока по три слота, данные на 80 бит дальше), данные, таблицы и массивы только до первого блока (иначе `bad block`), перед каждым
  выравнивающим зазором строка `# a <k> <зазор>`, пары ссылок на блок кончаются `+f0`; `l3c` пишет прежнюю серийную раскладку. Проход `l3p` (языки 1–3, A=20; читает
  вывод `l3c`, пишет текст для `l2l`, нулевой байт в конце) для каждого блока забывает пустые строки (ожидания `lut`, `if`, `ret`) и кладёт строки заново в слои не
  больше чем по две строки: список-планировщик `l3.py` без прямых записей — строка идёт в первый слой, куда её пускают предыдущие (после строки, что пишет то, что она
  читает или пишет, или читает то, что она пишет, — через слой; после строки, что пишет в текст её строки или в прыжок последнего слоя, — через два), где есть место и
  нет общих бит в такте (источник с источником тоже); смотрит на 8 строк назад, дальше — через два слоя после всех. Данные и таблицы не двигаются; таблица `if` и пара
  `call` после блока едут с его концом. Ошибки: `l3p: bad text`, `l3p: too big` (блок длиннее 254 слоёв). Цепочка с планировщиком: **текст языка 3 (`pack …`) → `l3c` →
  `l3p` → `l2l` → `seed` → образ (P=3)**; образ запускают `-p 3`. Эталон — `l3ctext.py` (`encode` с `pack`, `pack_pass`, `-p`); выбор раскладки по цене — язык 5
  (`l5.replace_layout`: серийная или упакованная, где дешевле по `price`; нижние языки цены не знают, им достаётся слово `pack`). **Неподвижная точка с упаковкой:** `l3c`,
  собранный серийной цепочкой с `l3p` из текста `pack` + `l3c.tw`, — упакованный `l3c`; он собирает из того же текста тот же текст языка 2, языка 1 и тот же образ побайтно.
  Не сделано: прямая запись в процессор (дыры, 23.3 г): `lut` остаётся в 4 слоях, `if` в 6; переходы и таблицы `if`/`call` не участвуют в расписании; окно 8 строк; 3 слота.
  Тесты: `tests/test_l3p.py` (в `check-tower`), класс `PackedFixedPoint` в `tests/long_l3c.py`. Замеры — `docs/measurements/tower.md`, раздел 17.
- **Временно:** Python остаётся эталоном и порождает тексты зерна: `l2.py`–`l5.py`, `lib.py`, `text.py` (разбор текста `.tw`, метки, проверки), `progs.py`, `l1.py`,
  `l1text.py` (генератор `seed.l1`, `l2c.l1`, `l2l.l1`; Python-эталон кодера; **первый `seed.img` из `seed.l1`**), `l2text.py`, `l2ltext.py`, `l3ctext.py`
  (эталоны `l2c`, `l2l`, `l3c`, `l3p`; `-l` печатает `l3c.l1`). Зерно, с которого цепочка идёт без Python: **эмулятор + `seed.img` + `seed.l1`, `l2l.l1`, `l3c.l1`**
  (тексты языка 1; их создал Python один раз, цепочка воспроизводит их сама). После правки `l3c.tw`, `l2l.tw`, `seed.tw` тексты пересоздают (команды ниже; тесты
  `…_is_current` скажут). Заменять Python-эталоны программами цепочки — дальше (23.11–23.12).
- Ошибка текста языка 1 — сообщение в stderr (слово `warn`, канал S+3) и останов: образ обрывается на этом месте
  (7.2.28, без исключений). Не проверяются (определено, но дорого): число длиннее 5 цифр, значение шире `w` бит,
  `w`/`z` больше `ff`.

## Как собрать и проверить

    make -C emulator all checked                           # эмулятор (тесты делают это сами)
    python3 -B tower/l1text.py tower/programs/seed.tw > tower/programs/seed.l1    # заново сгенерировать зерно
    python3 -B -m tower.text < tower/programs/echo.tw > echo.img                  # текст .tw -> образ (Python)
    python3 -B tower/l1text.py -e < tower/programs/seed.l1 > seed.img             # текст языка 1 -> образ (Python)
    # то же в пространстве: образ, текст и нулевой байт на stdin эмулятора (A=16, P=7 печатает text.py)
    { cat seed.img; cat tower/programs/seed.l1; printf '\0'; } | emulator/build/bitcopy/emulator -s 65530 -p 7 | cmp - seed.img
    python3 -B tower/l1text.py tower/programs/l2c.tw > tower/programs/l2c.l1     # зерно шага B (как seed.l1)
    python3 -B tower/l2text.py tower/programs/l2c.l1 > tower/programs/l2c.l2     # то же, копии как `c n d s`
    python3 -B tower/l2text.py -e < prog.l2 > prog.l1z                            # эталон l2c: язык 2 -> язык 1 + 0
    # цепочка: seed.img(l2c.l1) = l2c.img; l2c.img(prog.l2) = текст языка 1; seed.img(он) = образ (A=18, P=19 у l2c)
    python3 -B tower/l1text.py tower/programs/l2l.tw > tower/programs/l2l.l1     # инструмент меток (так же: .l2 из .l1)
    python3 -B tower/l2ltext.py -e < prog.l2 > prog.l1z                           # эталон l2l (сам удваивает текст)
    # l2l.img = seed.img(l2l.l1); текст дважды на stdin эмулятора (A=19, P=20 печатает text.py):
    { cat l2l.img; cat prog.l2; printf '\0'; cat prog.l2; printf '\0'; } | emulator/build/bitcopy/emulator -s 524282 -p 20 > prog.l1z
    # язык 3: l3c.img (серийная раскладка) -> текст языка 2 -> l2l (дважды) -> seed -> образ (A=20, P=2)
    python3 -B tower/l3ctext.py -t > l3c.img                                       # образ l3c, который собрал Python (A=20, P=3)
    python3 -B tower/l3ctext.py -e < prog.tw > prog.l2z                           # эталон l3c (программы с данными в блоках: l3ctext.hoist)
    { cat l3c.img; cat prog.tw; printf '\0'; } | emulator/build/bitcopy/emulator -s 1048570 -p 3 > prog.l2z
    python3 -B tower/l3ctext.py -l < tower/programs/l3c.tw > tower/programs/l3c.l1   # эталон всей цепочки l3c -> l2l: заново сгенерировать зерно l3c
    # планировщик (23.10): текст с первым словом `pack`; l3c пишет серийный текст, l3p упаковывает блоки, дальше как обычно (A=20, P=3 у образа);
    # l3p.img собирается, как любая программа (l3c.img на l3p.tw -> l2l -> seed)
    { cat l3c.img; printf 'pack\n'; cat prog.tw; printf '\0'; } | emulator/build/bitcopy/emulator -s 1048570 -p 2 > prog.l2s     # серийный выход режима pack
    { cat l3p.img; cat prog.l2s; } | emulator/build/bitcopy/emulator -s 1048570 -p 2 > prog.l2z                                  # упаковано; эталон: l3ctext.py -p
    python3 -B tower/l3ctext.py -l < prog.tw > prog.l1   # для текста с `pack` первым словом -l включает проход (эталон l3c -> l3p -> l2l)
    make check-tower                                       # все тесты цепочки (checked, ~90 с)
    make check-tower-long                                  # долгие: инструменты, собранные l3c, неподвижная точка (~155 с; входит в check-full, не в check-fast)

### Вся цепочка из зерна, без Python-компиляторов (23.9, часть 3)

Нужны эмулятор, `seed.img` (один раз: `python3 -B tower/l1text.py -e < tower/programs/seed.l1 > seed.img`; дальше `seed.img` на `seed.l1` даёт себя) и тексты языка 1
(`seed.l1`, `l2l.l1`, `l3c.l1`). `E` — эмулятор; `-s` — 2^A − 6, `-p` — P образа (`seed` A=16, P=7; `l2l` A=19, P=20; `l3c` A=20, P=2):

    E=emulator/build/bitcopy/emulator; T=tower/programs
    { cat seed.img; cat $T/l2l.l1; printf '\0'; } | $E -s 65530 -p 7 > l2l.img          # label tool (8,46 -> 12,0 млн тактов)
    { cat seed.img; cat $T/l3c.l1; printf '\0'; } | $E -s 65530 -p 7 > l3c.img          # l3c: 26,9 млн
    { cat l3c.img; cat $T/l3c.tw; printf '\0'; } | $E -s 1048570 -p 2 > l3c.l2          # текст l3c на языке 3 -> язык 2 с метками: 57,9 млн
    { cat l2l.img; cat l3c.l2; cat l3c.l2; } | $E -s 524282 -p 20 > l3c.l1.new           # метки, текст дважды: 19,2 млн
    { cat seed.img; cat l3c.l1.new; } | $E -s 65530 -p 7 > l3c.img.new                  # образ: 26,9 млн
    head -c -1 l3c.l1.new | cmp - $T/l3c.l1; cmp l3c.img l3c.img.new                      # L1 = L0: оба равны

Любой другой текст языка 3 из подмножества собирается так же (`l3c.img` на нём вместо `l3c.tw`). Всё вместе — 26 с на обычном эмуляторе; на `checked` 6, 13, 12, 34, 13 с.

Эмулятор получает `образ + текст + 0` на stdin, как в `common.run`. После правки `seed.tw`
пересоздать `seed.l1` (тест `test_seed_text_is_current` скажет, если забыли).
