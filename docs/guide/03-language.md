# 3. Язык

Язык проекта — **цепочка вложенных языков** 1–5 и Форт сверху. Каждый язык — несколько слов и компилятор в язык ниже; о языках выше он ничего не знает. Всё определение — один документ: [tower/README.md](../../tower/README.md) (понятия — раздел 2, слова всех языков — раздел 3, сколько слов — раздел 4). Здесь только то, как им пользоваться; прежний язык (ядро, образ L0) удалён из `main` — архив, тег `archive-2026-11-10`.

## Из чего состоит

| Язык | Что умеет | Раздел |
|---|---|---|
| 1 | одна строка копирования из четырёх чисел | 3.1 |
| 2 | три числа вместо четырёх, данные, метки | 3.2 |
| 3 | таблицы, блоки, переходы, вызовы, ввод-вывод, арифметика | 3.4 |
| 4 | длинное копирование ([глава 4](04-long-copy.md)) | 3.5 |
| 5 | цена программы (пока только на Python) | 3.6 |
| Форт | обычный язык сверху, 64 слова | 3.7 |

Языки 1–3 — ассемблер машины копий, обычные программы пишут на Форте. Компиляторы языков 1–3 — программы цепочки, написанные на языке 3; каждый работает в своём пространстве, а компиляция идёт проходами: каждый читает stdin и пишет stdout (схема проходов — [README, часть 6](../../README.md#часть-6-цепочка-языков)). Из слов получаются копирования так, как рассказано в [главе 1](01-space.md): таблица, косвенность, переход.

## Как собрать и запустить

Всё собирается из текста языка 1 и эмулятора; команды для каждого шага (зерно, компиляторы, программа, упаковка, проход длинных копирований, неподвижная точка) — в [tower/README.md, раздел 8](../../tower/README.md). Размер пространства и число строк процессора для каждой программы там же (`-s`, `-p`, см. [главу 2](02-emulator.md)).

Ошибок в языке нет: неверный текст — сообщение в stderr и останов; то, что пока не решено, получает **запретительную цену** ([словарь](../dictionary.md#цена-и-запретительная-цена)).

## Как проверить

```sh
make              # эмулятор
make check-tower  # тесты цепочки на режиме checked (несколько минут, входит в check-fast)
make check-tower-long   # долгие: собранные цепочкой инструменты, неподвижные точки, слова языка 4, 37 программ (входит в check-full)
```

Самосборка: `l3c`, собравший собственный текст, даёт тот же образ байт в байт ([раздел 6](../../tower/README.md)). Непересечение — построение, а не доказательство ([раздел 5](../../tower/README.md)); режим `checked` эмулятора лишь проверяет.
