# 3. Язык

Язык — это слова, которые превращаются в копирования ([глава 1](01-space.md)) и исполняются [эмулятором](02-emulator.md). Понятия «слово», «определение», «основание», «ядро», «цена» — в [README](../../README.md#понятия). Справочник на каждое слово ядра — [language.md](../../language/doc/language.md); эта глава — обзор, как это устроено.

## Как выглядит программа

Язык записывается в стековой манере Форта. Число кладёт значение на **стек**, слово берёт значения со стека и кладёт результат. Комментарий `( a b -- c )` рядом со словом говорит, что оно берёт `a` и `b` (последнее — сверху) и оставляет `c`. Новое слово определяется так: `: имя … ;`. Программа заканчивается определением `main`.

```
: main 65 emit 3 4 + 60 + emit ;
```

Эта программа печатает `AC`: `65 emit` — буква с кодом 65, `3 4 +` кладёт 7, `60 +` даёт 67. Запуск (после `make`):

```sh
( cat language/build/L0.boot; printf ': main 65 emit 3 4 + 60 + emit ;\0' ) \
  | ./emulator/emulator -s 2147483648 -p 8
```

L0 ([глава 4](04-kernel.md)) читает программу до нулевого байта, компилирует её в копирования и запускает. Ошибка текста — не исключение: для неизвестного слова печатается `error -13 at foo` (у других ошибок свои номера), и программа не запускается. Исключений (`throw`/`catch`) в языке нет; останов — это NOP в процессоре.

## Определение языка — файлы `language/src/`

| Файл | Что в нём |
|---|---|
| `prelude.fth` | мелкие стековые слова (`nip`, `tuck`, `2dup`, …), которыми пользуются остальные файлы |
| `backend.fth` | строки и слои — само основание; поток бута; слово непересечения `dj-prove` |
| `compute.fth` | вычисление копированиями: таблицы, из которых копирование по вычисленному индексу берёт готовый ответ |
| `forthc.fth` | компилятор: словарь, запись слова, литералы, цена, платформы, раскладка пространства |
| `primitives.fth` | **генераторы** — слова, которые исполняются при компиляции и выдают код |
| `main.fth` | точка входа бута на хосте: читает текст, компилирует, печатает поток |
| `kernel.fth` | точка входа ядра: читает программу пользователя, доказывает, запускает |

Всего около 1 900 строк, и в них нет ни одного имени, не определённого в самом определении (`make -C language check-closure` печатает `external 0`).

## От слова до копирований

1. **Чтение.** Компилятор читает слово; если оно есть в словаре, берёт запись, иначе передаёт слову `literal` (разбора чисел в компиляторе нет, цифры — тоже слова); иначе — ошибка.
2. **Генератор или вызов.** Если слово — генератор (например, `+`, `dup`, `if`, `:`), компилятор его исполняет, и оно пишет строки. Если слово — определение, компилируется вызов. Генератор сам умеет считать значения, известные при компиляции (`3 4 +` даёт литерал 7 без кода).
3. **Строки и слои.** **Строка** — одно копирование (приёмник и источник); **слой** — ячейка строк, исполняемых за один такт; последняя строка слоя — ссылка на следующий слой. Составитель расписаний следит за правилом непересечения и раскладывает копирования по слоям: если два копирования читают одно место, они попадут в разные слои.
4. **Поток.** Слои выписываются в поток бута — образ пространства для эмулятора. Каждый вызов — переход по ссылке; возврат и `execute` — переход через таблицы ([глава 4](04-kernel.md)).

Арифметика и логика — тоже копирования: слой копирует индекс в строку-чтение, следующий слой читает ответ из таблицы. Поэтому слова вроде `+` стоят несколько слоёв, а не один такт.

## Запись слова и механизмы

Слово — не только код: компилятор ведёт для него запись из 16 ячеек — имя, вид, ячейка понятия, определения по платформам, цена, доказательство, стек прежних определений. Подробности — [word.md](../../language/doc/word.md). Синоним `: a b ;` — просто другое имя на ту же ячейку понятия, без кода ([replace.md](../../language/doc/replace.md)).

## Цена

Когда компилятор заканчивает слово, он знает его цену: размер (ячейки), биты, копирования, слои; для слов без циклов, рекурсии и вызова `execute` — точно (сумма по вызовам, при ветвлении — наибольшая ветвь), иначе пометка «по исполнению». Слово `cost` выдаёт эти числа, `price` сводит их в одно (сумма; слово можно заменить). Цена на хосте — время.

Что пока не решено или не должно происходить, получает **запретительную цену** `fc-forbid` (2^24 бит, копирований и слоёв — больше любого настоящего пути): так сделаны деление на 0, где путь ведёт в ячейку останова, и длинное копирование `long!`/`long@` в оценке цены ([глава 5](05-long-copy.md)). Это решение автора: не вводить ошибок и исключений, а считать запретное очень дорогим и удешевлять по мере разработки.
