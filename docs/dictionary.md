# Словарь проекта

**Словарь** — список понятий. **Понятие** — слово проекта, имеющее определение.
**Определение** формулируется через понятия, уже стоящие в словаре выше, либо
ссылкой на код или документ, если понятие базовое. Ссылок вперёд нет: порядок
записей — порядок определений. Одно понятие — одно слово; синонимы указаны
в записи через «также».

**Принцип проверки (цель, пока не реализована).** Слово словаря — слово Форта.
Утверждение, составленное из слов словаря, проверяется программой на Форте:
отдельным словом или выполнением последовательности слов. Базовое слово
Форта определяет себя само (как загрузчик пространства: он и есть своё
определение); все остальные определяются через уже определённые. Пока слова
словаря не реализованы на Форте, в записи указан документ или код, где понятие
фактически определено. Прикладные термины C, GCC и RV32I — в
ветке `archive/legacy`.

## Базовые понятия

- **Бит** — значение 0 или 1.
- **Пространство** — S позиций, в каждой хранится бит. Единственное действие
  в пространстве — копирование. S задаётся при запуске (`-s`, по умолчанию 65520).
  Определено в [emulator-contract.md](../emulator/doc/emulator-contract.md).
- **Позиция** — номер бита в пространстве, от 0 до S−1. Позиция 0 — старший бит
  байта 0, позиция 7 — младший бит байта 0.
- **Полуинтервал** — позиции от `low` включительно до `high` не включая;
  длина равна `high − low`.
- **Граница** — число `low` или `high` полуинтервала.
- **Копирование** — запись битов полуинтервала-**источника** в полуинтервал-
  **назначение** той же положительной длины.

## Описания копирований

- **Описание** — запись в пространстве, задающая одно копирование. Бывает двух
  видов: тройка и псевдоинструкция.
- **Тройка** (также: **копикод**, **копиинструкция**) — описание `[n,dst,src]`:
  `n` — длина, `dst` — первая позиция назначения, `src` — первая позиция источника.
  `n`, `dst`, `src` — **поля** описания.
- **Псевдоинструкция** (также: **индексинструкция**, **индексная запись**) —
  описание `[dst_low, dst_high, src_low, src_high]` из четырёх границ: первые две —
  границы полуинтервала назначения, последние две — границы полуинтервала
  источника. Занимает 4A бит, где A — число бит в записи S. Название «канал
  передачи сигнала» означает связь источника с назначением; это не устройство.
  Определено в [emulator-contract.md](../emulator/doc/emulator-contract.md).
- **Соответствие тройки и псевдоинструкции** — `dst_low = dst`, `dst_high = dst + n`,
  `src_low = src`, `src_high = src + n`. Обратно: `n = dst_high − dst_low`,
  `dst = dst_low`, `src = src_low`. Соответствие верно для обычных копирований
  с равными длинами; NOP и копирования с устройством — отдельные случаи.
- **NOP** — описание без источника (его длина равна 0); назначение игнорируется.
  Канонический NOP псевдоинструкции — `[0,0,0,0]`.

## Исполнение

- **Процессор** — область пространства, из которой в начале такта читаются
  все описания целиком. В индексной машине это позиции `[0, P·4A)`, где P — число
  псевдоинструкций (`-p`).
- **Такт** — чтение процессора, выполнение всех его копирований и фиксация
  результата. Следующий такт видит записанное, в том числе в процессоре.
- **Слой** — набор описаний, исполняемых за один такт.
- **Устройство** — то, что обслуживает хост: SYS, stdin, stdout, stderr.
  **Канал устройства** — адрес `C ≥ S` в описании: источник или назначение `[C,C]`
  вместо полуинтервала; длину задаёт буфер на другой стороне. Не путать с каналом
  передачи сигнала (см. «Псевдоинструкция»).
- **Хост** — процесс и операционная система, в которых исполняется машина и
  которые предоставляют реальные файлы и терминал через устройства.
- **Машина** — исполнитель, который по тактам исполняет процессор, состоящий
  из описаний одного вида.
- **Индексная машина** (также: **индексное пространство**, **emulator**) —
  машина, процессор которой состоит из псевдоинструкций. Реализована в
  [emulator/](../emulator/README.md).
- **Копимашина** (также: **копипространство**, **vm2**) — машина, процессор
  которой состоит из троек. Реализована двумя способами: интерпретатором в
  индексной машине и C-эталоном на хосте.
- **Физический такт** — такт индексной машины. **Виртуальный такт** — такт
  копимашины; в индексной машине он занимает один или несколько физических тактов.

## Образы и трансляция

- **Образ** — содержимое пространства (включая процессор), которое нужно
  загрузить для запуска программы.
- **Boot** — последовательность байт для канала stdin, устанавливающая образ в
  пространство через первый слой.
- **Эталон** — независимая реализация машины, с которой сравнивают результаты
  других реализаций.
- **C-эталон** — эталон копимашины, написанный на языке C и исполняемый на хосте:
  `vm2/tests/reference`. Сейчас служит только проверкой и замерами.
- **Трансляция** — преобразование описаний одного вида в описания другого.
- **Совместимый путь** — исполнение образа из троек интерпретатором, который
  работает в индексной машине: в каждом такте он читает тройки и вырабатывает
  псевдоинструкции. Запускатель `vm2`.
- **Прямой путь** — трансляция символического копикода в образ из
  псевдоинструкций один раз, до запуска; образ исполняет индексная машина
  непосредственно. ABI `vm2-direct-v1`, запускатель `vm2c`.
  Определён в `direct.md` (vm2, тег archive-2026-10-30).
- **Запись по полю** — копирование, назначение которого целиком совпадает с одним
  полем описания (`n`, `dst` или `src`) в процессоре. Прямой путь превращает её
  в обновление нужных границ псевдоинструкции.
- **Запись не по полю** — копирование в процессор, назначение которого не совпадает
  с полем описания: например, накрывает конец `dst` и начало `src`. Прямой путь
  её не поддерживает: в псевдоинструкции нет упакованных полей тройки.
  Аналогично **чтение не по полю** — копирование из процессора в данные.
