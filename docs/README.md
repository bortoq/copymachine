## Цели make и CI

| Цель | Что делает |
|---|---|
| `make` | эмулятор |
| `make check-fast` | тесты эмулятора (с режимом `checked`), `make check-tower` (цепочка языков 1–5), раскладка, контракт |
| `make check` | то же, что `check-fast` |
| `make check-full` | + `make check-tower-long`: инструменты, собранные цепочкой, неподвижные точки, слова языка 4, 37 программ (около 15 минут) |
| `make lint`, `make coverage` | ruff; покрытие эмулятора gcov |
| `sh tools/ci/fast.sh` | то же, что быстрое задание CI: lint, `check-fast`, лицензии, документация, покрытие |
| `sh tools/ci/docs.sh` | ссылки в Markdown и объём документации (меньше, чем в теге `archive-2026-10-30`) |

CI (`.github/workflows/`): `check.yml` — быстрый набор, эмулятор gcc/clang в release и с санитайзерами; `nightly.yml` — долгие цели цепочки.
