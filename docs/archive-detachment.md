# Отсоединение архива

Рабочий проект собирается, выполняет проверки, запускает Forth и создаёт
самостоятельные исходные выпуски без legacy/. Архив сохранён, но не является
зависимостью. Перенос реализации на Forth остаётся задачей этапа 9.

Из 20 прежних файловых ссылок в архив 10 файлов нативного C-эталона vm2
размещены обычными исходниками в space/vm2/tests/reference. Это независимый
тестовый контроль; он не исполняет программы основного пути vm2. Сохранены MIT,
первоначальные SHA256 и происхождение в reference/PROVENANCE.json.
Остальные старые инструменты, RV32I bulk/stream, их тесты и интеграция
оставлены только в архиве и исключены из обычных выпусков.

Убраны 15 ссылок build/dist/tmp у активных компонентов и 45 обратных
каталожных ссылок архива. Сборщики используют явные пути общего build/.
В активном дереве допустима только файловая ссылка emulator/emulator
для выбора собранного backend; это не ссылка на каталог или архив.

Обычная проверка структуры не читает legacy/MIGRATION.json.
Аудит сохранности архива выполняется отдельно:

```sh
python3 -B tools/check_layout.py
python3 -B tools/check_archive.py --require-local-history
```

Проверка отсутствия зависимости создаёт дерево из текущих исходников,
исключая legacy/ и прежние результаты сборок. Используются явно выбранные
хостовые компиляторы; готовые гостевые образы не переносятся.

```sh
make check-detached
make check-detached DETACHED_FLAGS=--releases
```

Проверяются оба backend emulator, copycode, vm2, RV32I, 12 сценариев Forth,
запуск из другого рабочего каталога и очистка с неизменным состоянием исходников.
При очистке гостевые образы удаляются, кэш хостового RISC-V компилятора сохраняется.
В полном режиме каждый выпуск собирается вне workspace, проверяет установку
там, где она предусмотрена, воспроизводимую упаковку и очистку.

Проверки последовательны: один CPU, nice=15, до 768 МиБ памяти и ограниченное
время каждого процесса. Размер файла по умолчанию ограничен 16 МиБ; только
полная матрица потокового copycode получает предел 512 МиБ для разрежённого
образа до 256 МиБ. Память ретранслятора проверяется независимо от длины потока.

Сохранены локальные журналы в build/verification/detachment/ и исходные журналы
build/detachment-*.log. Успешные стадии самостоятельных выпусков собраны
в build/verification/detachment/releases.json; журналы исключены из Git.
Архивный аудит сверяет 475 исходных записей, дополнительно выведенные из работы
исходники и HEAD трёх прежних Git-историй. Реестр изменений —
archive-detachment.json и legacy/MIGRATION.json.
