# Компоненты и переход на Forth

Это реестр текущих компонентов, а не отметка о завершённом переносе языка.
Подробный реестр всех отдельных программ и их приёмок остаётся задачей 9.12.
Python генерирует гостевой код на хосте; полученный код исполняется в пространстве.

| Компонент сейчас | Действующая реализация | Что должно исполняться на Forth | Роадмап |
|---|---|---|---|
| emulator/ | C, bitcopy и network | Хостовая машина и реальные устройства остаются на C | 1–2, 9.14 |
| space/forth/ | C pForth, адаптация RV32I, сборка Python | Полная среда языка, библиотеки, прямой компилятор и собственное ядро | 9.1–9.3, 9.6–9.7 |
| space/copycode/src/copycode/vm1/ | Python, четырёхиндексные генераторы | Память/арифметика, SYS, boot, сборщик образов, монитор, снимки | 9.3–9.4, 9.14 |
| space/copycode/src/copycode/vm1/schedule.py | Python, планировщик | Планирование тех же операций | 9.4 |
| space/copycode/src/copycode/vm1/optimize.py | Python, отдельный оптимизатор | Необязательные преобразования перед планированием | 9.4, после первого транслятора |
| space/copycode/src/copycode/vm2/ | Python, общие тройки, транспорт и протоколы | Общие библиотеки, IO, checkpoint/resume и trace | 9.4, 9.8, 9.14 |
| space/vm2/vm2compile/ | Python, постоянная трансляция адресов/копикода | Транслятор в индексный код | 9.8, 9.14 |
| space/vm2/vm2guest/ | Python-генератор гостевого интерпретатора | Интерпретатор изменяемого копикода и его построитель | 9.8 |
| space/rv32i/ | Python-генераторы, гостевой RV32I, C/ASM-адаптация | Эмулятор, арифметика, монитор и транслятор RV32I | 9.5, 9.9 |
| tools/run/, средства запуска компонентов | Python/shell, реальные процессы и дескрипторы | Гостевые части IO и диагностики переносятся; хостовое соединение каналов остаётся | 9.3, 9.14 |
| tools/test/, проверки компонентов | Python/C и независимые эталоны | Гостевые задания на Forth; независимые хостовые эталоны сохраняются | 9.12–9.13 |
| legacy/copy-space/: copy-c | Старый компилятор и окружение | Перенос отложен до отдельного решения | 9.10, 10 |
| legacy/copy-space/: GCC/newlib/Linux | Старые инструменты и незавершённые компоненты | Сначала отдельный перечень объёма; перенос отложен | 9.11, 11 |

Рабочие реализации остаются при потребителях до проверки замен. После приёмки
замены прежняя реализация переносится в общий legacy/ и исключается из рабочего
пути; независимый контроль запускается явно. Переходники не считаются реализацией
на Forth. Большие отложенные приложения не включены в ближайший базовый рубеж.

Нативный независимый эталон троек — space/vm2/tests/reference (C, MIT).
Он сохранён для проверок и сравнительных замеров; для сборки legacy/ не нужен.
Архивные bulk/stream и прежние сборщики не входят в обычный путь и выпуски.
