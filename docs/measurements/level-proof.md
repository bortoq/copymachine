# 23.21. Доказательство уровня: слово `copy n d s`

Опыт к 7.2.35: доказать уровень на простейшем слове — `copy n d s` языка 2, определённом строкой `r d d+n s s+n` (как у `l2c`). Инструменты: `tower/tests/levelproof.py`; проверки `test_level_proof.py` (в `check-tower`, 15 с) и `exp_level_proof.py` (`check-tower-long`, 9 мин на 12 ядрах). Текст и образ делает цепочка (`l2c` → `seed` → `checked`); Python строит тексты и сравнивает байты.

## 1. Обещание

Позиции в битах, S — число позиций, A — ширина поля, S < 2^A ≤ 2^20 (числа `l2c` — до 5 hex-цифр).
- **Вход:** 0 < n; 0 ≤ d, s; d+n ≤ S, s+n ≤ S; [d,d+n) и [s,s+n) не пересекаются (d = s тоже нельзя) и не пересекаются с другими интервалами того же такта (контракт эмулятора, источник/источник тоже).
- **Обещание:** после такта биты [d,d+n) равны прежним битам [s,s+n), остальные не изменились.
- **n = 0** — NOP, кроме d = s = S (две кодовые позиции канала: `checked` отвергает).

## 2. Перебор

Программа случая: процессор из 2 строк, 3 слоя. L0 грузит окно [b,b+W) из stdin, L1 — проверяемая строка `c n d s` и переход, L2 пишет окно в stdout; `-t 5`. Содержимое окна идёт после образа: один прогон `l2c`+`seed` на все содержимые.

**Содержимое.** Эмулятор копирует биты и не читает их: каждый выходной бит — копия одного входного или константа. Тогда обещание для всех 2^W содержимых равно обещанию для маршрута σ, а σ читается с трёх видов содержимого: нули, единицы и K = ⌈log2 W⌉ «плоскостей» (бит k номера позиции в каждой позиции). Код выходного бита j = σ(j); нули/единицы отличают копию от константы. Плюс 2 случайных (ловят не-копии вроде OR). Полный перебор содержимых не нужен.

## 3. Независимость от размера

Порога A0 перебором не получить: чтобы задеть все 5 нибблов, нужно A ≥ 17 (2^51 троек). Вместо порога — три условия:

- **X1 (`l2c`).** Вывод для `c n d s` — функция только (n,d,s): `r d (d+n) s (s+n)`, сумма по модулю 2^20 через `add` по таблице `add4` (полная, 2^9 записей; ниббл за ниббл) и `puthex` (цикл). Ширина A в этой ветке не читается. Проверено: каждый шаблон (a, b, перенос) на каждой из 5 позиций + 200 000 случайных. **Принято:** одинаковость шагов по тексту `l2c.tw`.
- **X2 (`seed`).** Поле = младшие A бит числа, младший первым, независимо от остальных полей. Проверено A = 1..24.
- **X3 (эмулятор).** Строка — четыре поля по A бит; семантика копии по контракту не зависит от S, кроме границ [0,S]. **Принято**: доверенная основа (контракт, проверка `checked` и перебор выше).

Тогда для A ≤ 20 и допустимого входа: d+n ≤ S < 2^A ≤ 2^20, суммы не переносятся за 2^20 и поля не обрезаются, поэтому строка декодируется ровно в (d, d+n, s, s+n), и по X3 выполнено обещание. От A зависит лишь ширина поля и отсутствие обрезки. При A > 20 определение `l2c` не годится (числа до 5 цифр): уровень доказан для A ≤ 20. Перебор при малом A проверяет сборку X1–X3, а не заменяет их.

Не покрыто: адреса в процессоре и текстах слоёв (косвенность — другой уровень), n ≥ 2^20.

## 4. Вывод для 7.2.35

**Схема работает** для слова, определение которого — один шаг по числам, а обещание — функция одного такта. Цена мала: 120 тыс. случаев × 10 содержимых за 6 минут. Но доказательство — не перебор: перебор проверяет сборку X1–X3, размер даёт рассуждение, базу (контракт) принимают.

**Что делает уровень доказуемым:** (1) *параметричность* — определение смотрит на адреса, не на значения бит; содержимое сводится к K+2 пробам; (2) размер входит только шириной поля и отсутствием обрезки, поэтому условие X проверяется; (3) определение — текст над числами без состояния, цифра за цифрой; (4) домен проверяет `checked` (непересечение) — в доказательстве нет «а если пересекается»; (5) обещание — до и после одного такта.

**Что будет трудным:**
- *Длинное копирование (язык 4)*: состояние хоста, SYS на несколько тактов; «после такта» заменяется «по завершении» (7.2.35), нужна индукция по кускам.
- *Вычисляемый адрес (`lut`, `store`)*: поле строки — данные, параметричности нет (значения — адреса): перебор по указателю 2^k, зависимость от k — снова рассуждение; обещание на два такта.
- *Общее пространство*: общего такта нет (7.2.32, 7.2.38), в обещание входит «когда»; доказывать придётся протокол воркеров, не слово.
- *Скрытые помощники* (`add` внутри определения): доказывать отдельно, иначе X1 держится на непроверенном образе.
