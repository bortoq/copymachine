# Механизмы ядра K (факты)

Источники: `space/forth/scripts/forthc/` (`forthc.fth` = F, `model.py` = M, `kernel.fth`, `main.fth`, `prelude.fth`), `space/copycode/forth/backend.fth`, `space/forth/doc/forthc.md`; граф определений — `docs/research/definition-graph.md`.

Общие факты:

- Компилятор K (F) компилирует исходник целиком из буфера `fc-text`; интерпретатора, исполняющего слова во время компиляции, нет. Слова самого компилятора исполняются на хосте (pForth) или, в K, как уже скомпилированный код (kernel.fth: `main` запускает `kn-compile`, затем `cc-start-cell @ execute`).
- M — эталонная модель (Python), F пишет тот же поток побайтно (`forthc.fth:3-4`). Каждое поведение продублировано в двух местах; в таблице указаны оба.
- Слов `IMMEDIATE`, `STATE`, `[`, `]`, `POSTPONE`, `DOES>`, `EVALUATE`, `PARSE`, `WORD`, `'` (вне `[']`), `>NUMBER` в исходниках K и F нет (`grep`); `source` и `>in` в prelude.fth — заглушки (`prelude.fth:50-51`).
- Признак «зашито»: ветка по имени, таблица примитивов или жёсткая проверка внутри кода компилятора; определение, которое можно заменить новым `:`, зашитым не считается.

## Замечания по проверке «зашито»

- Порядок проверки имён в `fc-word-token`/`fc-control-token`: `;`, `exit`, `recurse`, `[']`, `[char]`, `s"`, `pick`, `space!`, `spacec!`, `roll` (F:767-775), затем управляющие слова (F:740-762), затем `fc-find` (F:763), `fc-number` (F:764), `fc-primitive` (F:765). Имена первых двух групп определением `:` не перекрываются (проверка выше `fc-find`); в M тот же порядок (M:655-736 до M:737).
- Примитивы из `fc-primitive` (F:765) проверяются после `fc-find` и `fc-number`, то есть слово с таким именем, определённое через `:`, перекрыло бы примитив при последующих вызовах из компилируемого текста (но не повлияло бы на уже скомпилированный код компилятора).
- Слова вне компилятора, которыми пользуется ядро, определены через `:`: `kn-put`, `kn-order`, `kn-compile`, `kn-.n`, `main` (kernel.fth), `fc-read`, `fc-sizes`, `main` (main.fth), слова prelude.fth; `cc-sink`, `cc-start-cell`, `cc-tx` — векторы (`@ execute`), их можно перезаписать (граф: 27 пар вектор-слово).
